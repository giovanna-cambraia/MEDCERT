# IEC 60601-1-4 — Programmable Electronic Medical Systems (PEMS)

Collateral standard for PEMS. This is where the architecture connecting
device-side C, host-side Ada reference models, and any programmable logic
gets documented, along with PEMS-specific verification activities
(architecture verification, revalidation on change).

- pems_architecture/  — PEMS block diagram, hardware/software partitioning
- pems_verification/  — verification activities specific to PEMS (distinct
                         from the IEC 62304 software verification records)
